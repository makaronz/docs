Studio is the operator workspace where you preview the camera feed, edit on-stream overlays, start and stop the broadcast, and configure simulcast targets for a single stream.

Use Studio when you are about to go live or are already on air. For setup that happens before a stream exists (creating the stream, choosing the provider), use the event editor instead.

## Layout

A Studio session is bound to one stream ID and is split into three columns:

- **Left** — chat with viewers.
- **Center** — video preview with the overlay canvas, the live duration timer, the On-Air toggle, and Start / End stream controls.
- **Right** — overlay library, the overlay inspector, and tabs for interactions, simulcast, and the AI copilot.
